# Reporting security issues

For a suspected vulnerability, use GitHub private vulnerability reporting if the repository owner has enabled it. Otherwise contact the owner through a private channel they publish. Do not put secrets or exploit details into a public issue.

Updates are local source ZIPs, not signed releases. Install only archives from a source you trust. Archive validation checks paths and sizes, not code trustworthiness. A failed update may require restoring the previous files from `data/old_versions/`; updates are not transactional.

Recognition runs locally. Installation downloads Python dependencies. Fishing recordings contain selected screen crops and physical A/D/LMB states while the bound game is foreground, stored locally under `data/fishing_sessions/`. Review crops before sharing.
